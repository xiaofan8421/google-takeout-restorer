# Google Takeout 恢复器

把 Google 相册 Takeout 导出的散装文件，整理成按拍摄时间归档、Live Photo 成对、同名不覆盖的本地相册。

官方导出和常见的 Takeout 整理脚本，经常把相册拆坏。这个工具对着那几件最烦的事做了修复。

## 它解决什么

**Live Photo 被拆开（最主要）**

一条 Live Photo 本来是一张静图加一段短视频，常见是 HEIC + MOV。导出之后，短视频经常没有拍摄时间。传统工具按各自的时间归档，照片进了某年某月，视频却掉进别的目录，再导入相册时已经不是一对。

本工具在同一文件夹里把同名的图片和短视频绑在一起：短视频继承照片的拍摄时间和位置，并落到同一个年月目录、同一个文件名，只保留各自的后缀。

**多部手机同名，互相覆盖**

每台手机都会从 `IMG_0001` 重新编号。传统工具按文件名保存，后一部手机的照片会盖掉前一部。

本工具用来源目录生成一段短哈希，写进文件名。不同手机、不同相册里的同名文件会并存。

**年份目录丢了**

Takeout 里常常是一堆平铺文件，或只有 Google 自己的相册名，没有「年 / 年月」。

本工具读取 JSON 里的拍摄时间，输出成：

```text
2023/
  2023-06/
    20230601_120000_IMG_0001_a1b2.heic
    20230601_120000_IMG_0001_a1b2.mov
```

**没有日期的文件被乱丢**

读不到拍摄时间时，文件不会散进错误的月份。它们统一放进 `Unknown_Date/`，并同样带上目录哈希，避免同名覆盖。

另外还会匹配 Google 截断后的 JSON 边车文件，把拍摄时间写回文件修改时间。安装了 `piexif` 时，也会写入 JPEG 的 EXIF。

## 用法

```bash
python3 google_takeout_restorer.py -i ./Takeout -o ./GooglePhotos_Restored
```

`-i` 是解压后的 Takeout 根目录，`-o` 是整理结果。原文件不会被修改，只会复制到输出目录。

可选：把拍摄时间写进 JPEG EXIF。

```bash
pip3 install piexif
```

不安装也能用，时间会写在文件的修改时间上。

## 文件名

`拍摄时间_原文件名_目录哈希.后缀`

两部手机都有 `IMG_0001.HEIC` 时，会变成两个文件，例如：

- `20230601_120000_IMG_0001_a1b2.heic`
- `20230601_120000_IMG_0001_c3d4.heic`

同一条 Live Photo 的短视频使用同一个主文件名。
